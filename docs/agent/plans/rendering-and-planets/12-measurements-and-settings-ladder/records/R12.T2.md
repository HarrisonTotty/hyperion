# R12.T2: records as built

The as-built records of R12.T2, moved from the Risks and open points of
[12-measurements-and-settings-ladder.md](../../12-measurements-and-settings-ladder.md). A new record goes at the end, in the same form.

- **Platform audit (lean, 2026-11-13).** Off Linux every `/sys` reading is `null` with its reason;
  on macOS `sampleThermal` reads `pmset -g therm` (no root, as `scripts/macProfile.mjs` does) and
  nothing needs `powermetrics`. `checkQuiet` takes `quietOf` (`main/machineLoad.ts`), so a Windows
  record is `forced`, its quiet rule unchecked, never quiet on `os.loadavg()`'s zeros; the governor
  is `null` off Linux.

- **R12.T2, as built.** `describeMachine(inputs, sources)` is async (Chromium's GPU information is a
  promise) and takes `MachineInputs` (slug, adapter, capabilities, kernel paths, card, Ozone
  platform) from the runner; `nodeMachineSources({ gpuInfo, display, appVersion })` takes Electron's
  parts. `samplers.ts` adds `NvidiaClockStream` (one `nvidia-smi --query-gpu … -lms 100` child),
  `GpuClockSampler` and `PerfSampler` (10 Hz; `summarise(fromMs, toMs)` gives `ThrottleFigures`).
- **R12.T2, as built (2).** `checkQuiet(sources)` gives `PreconditionReport` (`quiet`, `refusals`
  for `forcedReasons`, `state`, `cooledMs`), waiting up to 5 min for the package below 60 °C. A
  desktop passes as always on AC, settling R12.T9's open point (lean, 2026-11-17); an unread supply
  or temperature is a refusal, unchecked as Windows's load is. `ThrottleFigures` adds
  `gpuThrottleShare`, `cpuMedianMHz`, `zoneMaxDegC` and `packageWatts`.
- **R12.T2, pending the owner.** The `/sys` fixtures are written from the kernel's documented
  layout; the X1 Yoga's and the desktop's captures, and whether driver 615.71.09 takes the
  `clocks_event_reasons.*` query fields, are the owner's (NOT RUN in a pod).
- **R12.T2, as built (3).** `sampleThermal(sources, atMs)` and `sampleThrottle(sources, gpu, atMs)`
  take injected sources and the sample's time. Without a `Mains` supply, a system battery not
  discharging reads `mains`, and no power-supply class reads `desktop`; macOS waits up to 5 min for
  `pmset -g therm` to clear. On NVIDIA `rp0Share` is `null` (GPU Boost runs below `clocks.max.gr`
  unthrottled) and `gpuThrottleShare` stands in.
- **R12.T2, the laptop's capture (2026-11-18).** The `x1-yoga` tree is now captured from the
  UHD 620 laptop, replacing the written one.
  - Seven thermal zones, not six. `SEN1` and `iwlwifi_1` both have a reading. The case of a zone
    with no reading is now a test of its own, with a denied file.

  - The second UCSI source is online.

    run's.
  - TLP 1.11's `tlp-stat -s` joins the command fixtures (`performance/PRF`), with its `System` and
    `/proc/cmdline` lines trimmed.
  - `energy_uj` stays written, since it is root-only there.
