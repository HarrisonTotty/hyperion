# R12.T4.a: records as built

The as-built records of R12.T4.a, moved from the Risks and open points of
[12-measurements-and-settings-ladder.md](../../12-measurements-and-settings-ladder.md). A new record goes at the end, in the same form.

- **Platform audit, the launch (lean, 2026-11-13).** As built, `gpuTiming` applies in every mode but
  `safe` (`graphics/switches.ts`), so perf mode passes the toggle off Linux too.
- **Whether Metal and D3D12 honour it is unverified** (pending the owner's Mac run): the Mac A/B of
  2026-11-01 read quantized, before the toggle reached `default`, and `timerOf` reads `full` from
  the flag alone.
- **Quantized timers, recorded.** T4.c records `quantized` where every pass time is a multiple of
  65,536 ns (`smoke/work.ts` counts them).

- **R12.T4.a, as built.** `PerfLaunch` (`preload/api.ts`) is `ClientArgs.perf`: the scene, the
  `--setting`, `out` (`null` for `target/perf-run/runs.v1.jsonl`, JSON lines that `just perf-record`
  adds), `repetitions` (1 to 50, five by default), `control` and `force`.
- **Flags and switches.** A flag's variable is on when set to any value, as commander reads it.
  `main/perf/launch.ts`'s `perfSwitches` is R01's `graphicsSwitches` with `perfGpuTiming`.
- **The toggle's modes.** `perfGpuTiming` holds in every mode but `safe`, unless the control run,
  and `--perf-control` is refused beside `--hyperion-gpu-timing`.
