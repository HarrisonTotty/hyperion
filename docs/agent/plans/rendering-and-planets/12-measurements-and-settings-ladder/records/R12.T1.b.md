# R12.T1.b: records as built

The as-built records of R12.T1.b, moved from the Risks and open points of
[12-measurements-and-settings-ladder.md](../../12-measurements-and-settings-ladder.md). A new record goes at the end, in the same form.

- **R12.T1.b, as built.** `budget.md`'s sections (`frame-time`, `memory`, `streaming`, `runs`)
  lie between two identical `<!-- generated:<name> -->` markers, inside Prettier's ignore
  markers. Its columns are `table.ts`'s `BUDGET_COLUMNS`, matched by the GPU's PCI IDs (the Mac's
  by platform and CPU); a cell takes its column's latest record with the row, preferring a `full`
  timer. The scenes' verdicts stay prose for T8, which judges them with T5.a's criteria. Added:
  `store.ts` (`appendRecords` numbers IDs and refuses a duplicate; `recordsOfFile`) and
  `stats.ts`. `foldSpikeResult` folds every results file in `docs/measurements/descent-spike/` (twelve,
  a test checks), a hidden run as `virtual`; their IDs carry R05's machine name, for T8.a to keep or rename. The package's
  tsconfig is solution-style (`tsconfig.lib.json`, `tsconfig.node.json`), as the app's is.
- **R12.T1.b, as built (2).** A fold takes its views' rate and pacing from its setting, its server
  as `local` with `numWorkers: null` (R05's file does not say), its GPU busy time as `null` (R05
  times the GPU process's CPU side) and its demand as R05's calibrated prediction; a provisional R05
  run is `forced`. The tables add a `frames` section (ranges, pooled p99, missed fraction) and show
  a co-resident station run marked, never as the station's figure. `FRAME_ESTIMATES` keep each
  row's `upperMs` for Design note 10. `just smart-ci` sends `budget.md` to Prettier alone, so the
  sync test runs under `just ci`, not a task's gate (findings).
