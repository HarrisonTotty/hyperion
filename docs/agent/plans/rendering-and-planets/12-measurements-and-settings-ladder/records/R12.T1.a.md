# R12.T1.a: records as built

The as-built records of R12.T1.a, moved from the Risks and open points of
[12-measurements-and-settings-ladder.md](../../12-measurements-and-settings-ladder.md). A new record goes at the end, in the same form.

- **R12.T1.a, as built.** `engines.node` already reads `>=26.0.0`, above `>=22.18.0`, so its
  raise is moot. `PerfRunRecord` adds `pooledFrames`, `scene.world` and `harness`'s `switches`,
  `launchMode`, `forcedReasons` and `vsyncPeriodMs`; `commit` and `generatorVersion` are `null` on
  a fold (a `perf-run` states them, at a scene version from 1; a fold's is 0); `MEMORY_ITEMS` is
  T3.a's. Added: `validatePerfRecord`, `parsePerfRecords`, `serialisePerfRecord`, `perfRecordId`.
  The boundary test leaves out `src/cli/` and `src/test/`, which run under Node
  (`tsconfig.node.json`); `apps/hyperion`'s `tsconfig.node.json` and `tsconfig.web.json` gain
  `allowImportingTsExtensions` for the package's `.ts` imports.
- **R12.T1.a, as built (2).** `lineAntialiasing`, `exposure`, `warmUp.steady`, `heightWorkers` and
  `repetitionSeconds` are nullable so that a fold validates; a `perf-run` states all but `exposure`
  (R02 has no EV-range type yet). `MemoryFigures` already holds Design note 6's other lines
  (`workerWasmBytes`, `nvidiaDeviceLessBaselinePeakBytes`, `displayServer`), for T3.b to fill
  without a version bump. The Mac lean adds `platform` `darwin`, `windowSystem` `macos` and
  `profile.lowPowerMode`; `FrameFigures.source` adds R05's `gpu-completion`.
