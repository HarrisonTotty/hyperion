# Primary Gameplay Resources & Variables

This document describes the primary resources and variables the players must balance during the course of gameplay.

## Health & Shields

Each ship component has a separate health pool, with no global hit point value. It may also have a shield if a shield generator is present and enabled.

## Credits

The game's primary currency system is in _credits_. It's used to purchase new parts, inventory, fuel, etc.

## Fuel

The players' ship usually has a limited amount of fuel, depending on type of propulsion it is outfitted with. Some engines directly draw from the ship's power capacity as fuel, while others have dedicated fuel tanks.

## Power

Ships have the ability to generate and store power. Power consumption rate can be adjusted for various systems, which affects their performance.

## Heating / Cooling

Ship systems generate heat, which when left unmanaged can damage components. If a fire breaks out, nearby components will start to take damage as well.
