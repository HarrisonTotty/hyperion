# HYPERION Spaceship Bridge Simulation Game

HYPERION is a spaceship bridge simulation game that is a mixture between Artemis
and No Man's Sky. Players work together as positions on a ship as they navigate
an actual-size procedurally-generated galaxy.

## Core Features

### Powered By Rust, Electron, and Typescript

The game server (`hyperion-server`) is written in Rust, while HYPERION's frontend
(`hyperion`) is written as an Electron+React typescript application.

### Everything is Procedually Generated

Alien races, factions, languages, civilization history, planets and their
biomes, solar systems, stars - all of it is procedurally generated with
realistic parameters.

### Embedded LLMs for Enrichment

Local models like Gemma 4 are invoked to generate detailed descriptions where
needed.

### Extensive Realism

Every aspect of the simulation and the frontend is crafted to provide a
exceptionally realistic experience. Plant size, behavior, and composition
reflects real astrophysical expectation. Each station console offers
flight-simulator-level attention to detail.
